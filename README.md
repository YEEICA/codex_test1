# AI 观测 / The AI Observer

高级黑白风格的 AI 资讯精选网页。单文件静态站点，无构建依赖。

## 内容与功能

- 本期 7 条资讯，覆盖 OpenAI、Google、Microsoft、Anthropic、百度和腾讯。
- 每条提供发布日期、背景、摘要、内容、核验说明及官方原文链接。
- 支持关键词搜索、机构筛选、时间排序和详情展开。
- 适配桌面及移动端。

资讯为 2026 年 10 月 17 日人工检索核验快照，尚未接入自动采集。

## 本地预览

直接打开 `index.html`，或运行：

```sh
python -m http.server 8766 --bind 127.0.0.1
```
